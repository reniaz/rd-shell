# qs-bar

## Agents

Every goal and every prompt in this directory may use up to 10 agents, whenever
they are needed or useful — no need to ask first. Standing permission, not a
per-task grant.

The split follows the global rule: writing agents never share files, one shared
contract file in the scratchpad, and capacity beyond the natural file split goes
to read-only audit agents rather than to more writers.
