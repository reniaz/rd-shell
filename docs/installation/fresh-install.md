# Fresh install

This is the scenario `install.sh` is written for: a Fedora box, `dnf upgrade`
already run, a Hyprland session started at least once (so Hyprland's own
autogenerated default config may already exist under `~/.config/hypr`), and
none of this rice's configs in place yet.

```bash
git clone https://github.com/reniaz/rd-shell ~/coding/qs-bar
cd ~/coding/qs-bar
./install.sh
```

Answer the prompts as they come (or pass `-y` to accept everything). In order,
the script:

1. Enables the COPRs Hyprland/Quickshell/matugen, ghostty and yazi come from,
   plus RPM Fusion if it finds an NVIDIA card.
2. Installs every required and optional package it can detect is missing
   (now including `flatpak`), plus the toolchain nvim's plugins need
   (`nodejs22`+`nodejs22-npm-bin`, `ripgrep`, `fd-find`, a C toolchain,
   `golang`, `python3-pip`, `unzip`).
3. Builds `fetchit` (the terminal greeting) and, if you say yes,
   `wayvibes` from source — neither has a Fedora package.
4. Installs Material Symbols Rounded, the bundled `caelusevka` font, the
   Bibata cursor theme, and `starship` (its own curl installer, since
   Fedora has no package for it).
5. Symlinks the repo into place and links every config file, nvim included,
   then runs nvim's plugin manager headless so the first real launch isn't a
   plugin download (see [What install.sh does](what-install-does.md) for the
   exact list).
6. Wires up GTK/Qt/KDE theming, btop's and cava's colour themes, and the
   default terminal.
7. Clones the wallpaper set, adds the `hyprexpo` plugin (build deps
   installed first), masks any notification daemon competing for D-Bus,
   patches around a PipeWire crash some Iriun Webcam installs cause, and
   enables `hypridle`.
8. Renders the first matugen colour theme, so nothing on first launch points
   at a file that doesn't exist yet.
9. Installs Spotify as a per-user flatpak, sets up spicetify, and applies the
   `caelus24` theme — see [spicetify](../dotfiles/spicetify.md).

{% hint style="warning" %}
If Hyprland already auto-generated a `~/.config/hypr/hyprland.conf`, it's
copied to a backup (`hyprland.conf.bak-YYYYmmdd-HHMMSS`, original left in
place), **not** left as your active config. `hyprland.lua` (linked next to
it) is what actually loads on your **next full Hyprland restart** — logging
out and back in, or `uwsm stop` + relaunch; a plain `hyprctl reload` still
reads the old `hyprland.conf`. See [Installing over an existing
config](existing-config.md) if you want to keep your own `hyprland.conf`
instead.
{% endhint %}

## After the script finishes

The end-of-run summary lists a handful of things that are specific to *this*
machine and can't be installed for you — edit them before you log in:

- `hl.monitor(...)` and the `MAIN`/`SECOND` output names in `hypr/hyprland.lua`
  for your own monitor names (`hyprctl monitors` lists them), or delete both
  lines to let Hyprland auto-detect.
- `hl.env("LIBVA_DRIVER_NAME", "nvidia")` — delete it if you have no NVIDIA
  card.
- `input.kb_layout` — set to your own keyboard layouts. A second layout is
  what makes the keyboard pill and its OSD appear at all.
- `dotfiles/fetchit/init.lua`'s `gpu:` line — the only fetchit line still
  hand-typed for the machine this rice was built on; edit it for your own
  card (see [fetchit](../dotfiles/fetchit.md)).
- The login-screen wallpaper needs a one-time root setup
  (`sudo install -d ... /usr/share/backgrounds/rd-shell`, then pointing
  `/etc/plasmalogin.conf` at it) before plasmalogin follows the wallpaper too
  — the exact commands are in the end-of-run Summary.
- If Spotify was already installed system-wide, the Summary prints how to
  switch it to a per-user install so spicetify can theme it — see
  [spicetify](../dotfiles/spicetify.md#install-spotify-as-a-per-user-flatpak-then-spicetify).
- Install Vesktop and Signal yourself if you want them (`flatpak install
  flathub dev.vencord.Vesktop org.signal.Signal`) — both autostart from
  `hyprland.lua` if present, but neither is installed by `install.sh`; their
  matugen themes are already linked and pick up the current wallpaper as
  soon as the apps exist.

Then log out and pick **Hyprland** at the login screen. Autostart the bar with
`launch.sh` (already wired into `hyprland.lua`) rather than `qs` directly — it
brings the audio graph up first, or the bar starts at 0% volume with no mic
pill for the rest of the session.

Full detail on every step: [What install.sh does](what-install-does.md).
