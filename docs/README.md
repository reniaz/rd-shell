# rd shell

`rd-shell` is a [Quickshell](https://quickshell.outfoxxed.me) (QML) bar built for
a Lua-configured [Hyprland](https://hyprland.org) on Fedora 44. This wiki covers
the whole rice this repo ships: the bar itself, the Hyprland config it runs on
top of, the app dotfiles wired to [matugen](https://github.com/InioX/matugen)
wallpaper colours, and the one installer that puts all of it on a machine.

Repo: [reniaz/rd-shell](https://github.com/reniaz/rd-shell)

## Where to start

- **New machine?** Go to [Installation](installation/README.md).
- **Want a tour of the bar, popups and desktop widgets?** Go to
  [The shell](the-shell/README.md).
- **Looking for a specific keybind?** Go to [Keybinds](keybinds.md), or press
  `Super+K` on a running session.
- **Want to know how the wallpaper reaches every app?** Go to
  [Theming](theming/README.md).
- **Editing an app config directly?** Go to [Dotfiles](dotfiles/README.md).
- **Something broke?** Go to [Troubleshooting](troubleshooting.md).

## Stack at a glance

Hyprland · Quickshell · matugen · ghostty · hyprlauncher · fetchit · btop ·
cava · nvim · yazi · vesktop · spicetify.
